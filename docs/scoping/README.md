# Scoping

Information gathering for Aura Editor: motivation, goals, background, inspiration, and general context.

See [Silent Orb: Scoping and Design](https://silentorb.com/business/product/scoping-and-design/) and [`../README.md`](../README.md).

## What belongs here

- Vision and goals (why the product exists)
- Background constraints and forcing functions
- Sources of inspiration and external references
- Notes that may later refine into design

## What does not belong here

- Declarative product definition (see [`../design/`](../design/))
- One-off task scratch that will never inform design

## Style

Optimize for **capture** over perfect organization. Prefer adding a short note to an existing file. Design docs may link here for motivation origins.

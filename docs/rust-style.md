# Rust style guide

Living style for **Aura Editor** crates. Shared Aura/Imp-aligned Rust conventions (including **Errors**) live in the sibling engine guide:

- [aura-engine `docs/rust-style.md`](../aura-engine/docs/rust-style.md)

Follow that document for crate naming expectations and error-handling rules. Editor-specific GUI and OS-integration guidance belongs in this repo’s design docs, not as a divergent copy of shared Rust rules.
